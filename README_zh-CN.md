# Wanx 图片转视频

使用人工智能的力量,将静态图片转换为动态视频动画。这个工具通过在两个关键帧之间创建流畅的过渡,让您的图片活起来。

[English Documentation](README.md)

## 这个工具能做什么

您是否曾想过看到照片中两个瞬间之间发生了什么?这个工具使用人工智能创建一个视频,在两张图片之间流畅地制作动画。可以把它想象成创建一个电影场景,您只需要提供第一帧和最后一帧,人工智能会填充中间的所有动作。

## 主要功能

### 关键帧转视频生成器

这是从图片创建动画视频的核心功能。它可以做到:

**基本能力:**
- 接收两张图片(开始帧和结束帧)
- 创建在它们之间平滑过渡的视频动画
- 让您用简单的文字描述视频中应该发生什么
- 生成各种分辨率的高质量视频输出

**您可以控制的内容:**

- **开始和结束图片**: 提供定义视频开头和结尾的两个关键帧
- **视频描述**: 写一个简单的描述,说明您想看到什么(可选但推荐)
- **质量设置**: 从标准(480P)、高清(720P)或全高清(1080P)质量中选择
- **创意控制**: 告诉AI在视频中要避免哪些元素
- **一致性**: 使用相同的设置来重现相似的结果

**智能增强:**
工具可以自动用额外的细节增强您的描述,创建更生动、更逼真的动画。这有助于确保您的视频看起来专业,即使您不确定如何描述每个细节。

## 如何使用

### 基本用法

1. **准备您的图片**: 准备好两张图片 - 一张用于视频的开始,一张用于结束
2. **描述您的想法**: 写一个简单的描述,说明这两个时刻之间应该发生什么
3. **选择质量**: 选择最适合您需求的视频质量
4. **生成**: 让AI创建您的视频

### 实际示例

**示例1: 角色动画**
- 开始图片:一只企鹅静止站立
- 结束图片:同一只企鹅做出舞蹈姿势
- 描述:"一只企鹅表演霹雳舞动作"
- 结果:企鹅过渡到舞蹈动作的流畅视频

**示例2: 场景转换**
- 开始图片:白天的风景照片
- 结束图片:同一场景的日落时刻
- 描述:"太阳在风景上落下,颜色变化"
- 结果:展示过渡的延时风格视频

**示例3: 产品展示**
- 开始图片:产品在一个位置
- 结束图片:产品旋转或在不同角度
- 描述:"产品旋转以展示不同角度"
- 结果:专业的产品演示视频

### 获得最佳效果的技巧

- **使用清晰的图片**: 确保您的开始和结束图片都清晰且光线充足
- **详细描述**: 您在描述中提供的细节越多,AI就越能理解您的想法
- **匹配您的图片**: 两张图片应该相关 - 从相似的角度展示相同的主题或场景效果最好
- **尝试不同质量**: 从720P开始,在质量和处理时间之间取得良好平衡
- **避免不需要的元素**: 使用"要避免的元素"选项来防止特定内容出现在视频中

当您的视频准备好时,您将收到:
